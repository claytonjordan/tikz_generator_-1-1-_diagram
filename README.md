C++ code which can be used to generate TikZ code which will draw a (pretty nice) $4$-tuple $(1,1)$-diagram in LaTeX for a given $4$-tuple. Uses the $(p, a, b, r)$ parametrization found in Gabriel Doyle's paper, though it can easily be modified to work for the more prevalent $(p, q, r, s)$ convention presented by Jacob Rasmussen.
